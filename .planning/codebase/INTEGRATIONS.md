## Authentication & Identity

**Auth Provider:**
- Custom JWT-based authentication
  - Implementation: `app/auth.py`
  - Algorithm: HS256 (HMAC with SHA-256)
  - Token expiry: 5 minutes with rolling window extension
  - Password hashing: Argon2 via passlib
  - Secret key: Auto-generated 32-byte token (stored in `.env`)
  
**Session Management:**
- JWT tokens stored in Streamlit session_state (server-side)
- Endpoints: `POST /auth/teacher-login`, `POST /auth/verify-session`
- Role-based access: Teacher role required for Teacher Dashboard
- Login endpoints: `/auth/login` (students), `/auth/teacher-login` (teachers)

**Password Management:**
- Endpoints: `POST /auth/set-password`, `GET /auth/check-password/{uuid}`, `DELETE /auth/remove-password/{uuid}`
- Storage: `users.password_hash` column (Argon2 hashed)
- Minimum length: 6 characters (enforced in frontend and backend)
